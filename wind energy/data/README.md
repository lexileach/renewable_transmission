# Data

## The data for this project was selected to analyze the proximity of renewable energy sources to transmission lines in the US.

1. wind_turbines.geojson\
This data set provides onshore and offshore wind turbine locations in the US. This will be used to plot each wind turbine's proximate location, so we can measure the distance to a transmission line.\
**Source:** https://energy.usgs.gov/uswtdb/data/

2. transmission_lines.geojson\
This data provide the framework on the US grid with transmission lines spanning the entire country.
**Source:** https://gis-fws.opendata.arcgis.com/datasets/fws::us-electric-power-transmission-lines/about
